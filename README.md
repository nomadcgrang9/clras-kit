# 클라스 미션 코딩 꾸러미

경기도 클라스(CL:RAS) 선생님 미션 코딩 연수에서 쓰는 작업 도구 꾸러미입니다.
선생님의 AI(Codex·Claude 등)가 진행표(클라스미션_진행표.md)의 「1-1 꾸러미 확인」에서 이 릴리스를 받아 씁니다.

- 받는 주소(늘 최신): https://github.com/nomadcgrang9/clras-kit/releases/latest/download/clras-kit.zip (해시: clras-kit.zip.sha256)
- 들어 있는 것: 진행표, 감싸개(_도구\클라스.cmd·kit.mjs·창열기·창찍기), 설치 없이 쓰는 고정 판 도구
  - Node.js 22.23.3 (MIT) — https://nodejs.org/dist/v22.23.3/
  - MinGit 2.56.0.2 (GPLv2) — https://github.com/git-for-windows/git/releases/tag/v2.56.0.windows.2
  - GitHub CLI 2.102.0 (MIT) — https://github.com/cli/cli/releases/tag/v2.102.0
  - Eclipse Temurin JRE 21.0.12.1+1 (GPLv2 + Classpath Exception) — https://adoptium.net/
  - 각 도구는 공식 배포 파일을 해시 확인 뒤 그대로 넣었습니다(고치지 않음).
- 비밀값·학생 정보는 들어 있지 않습니다. 클라스 코드는 비공개 저장소에 있고, 초대받은 선생님만 받을 수 있습니다.
